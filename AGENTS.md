# Project defaults

Inherit global defaults; do not duplicate them. At task start, read docs/ai/PROJECT_CONTEXT.md once. For development, also read docs/ai/development.md. These references are explicitly read, not automatically injected.

Confirm scope, acceptance criteria, environment, and contracts. Treat TODO fields as unknown; label assumptions. Verify documented commands exist and report unavailable checks. Actively delegate useful independent work with bounded context and disjoint write ownership. When publication is authorized, use focused branches, Japanese GitHub artifacts, an Issue-linked PR, and a review of the published head.
